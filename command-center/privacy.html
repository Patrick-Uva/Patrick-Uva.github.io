Privacy policy

Command Center · effective 8 November 2026

Command Center is a private, single-user app. It runs on its owner's own computer and is used only by that person. This policy explains what it does with Google user data.

What data it accesses

Only after the owner signs in with Google and grants access, Command Center reads, using read-only permissions:

  • the list of the owner's calendars (name, colour, which one is primary), and
  • events from the calendars the owner chooses, from one week ago to two months ahead: title, start and end time, location, whether it is all-day or marked "free", and a link to the event.

It does not read email, contacts, files or any other Google data, and it never creates, changes or deletes calendar events.

How it is used

Calendar events are shown in the app's weekly planner and today view, and are compared with the owner's planned time blocks to spot clashes. If the owner asks the app's built-in assistant a question about their schedule, the relevant events are included in that request to the assistant's AI model, which the owner connects with their own ChatGPT sign-in, solely to answer that question.

Google user data is not used for advertising, is not sold, and is not used to train AI models.

Where it is stored

Everything is stored on the owner's own computer, in the app's local database. Google sign-in tokens are encrypted. There is no Command Center server or cloud service, and nothing is shared with anyone else.

Keeping and deleting data

  • Events outside the sync window are kept only as a local history and can be removed at any time.
  • "Disconnect" in the app revokes access at Google and deletes all imported calendar events.
  • Access can also be removed at myaccount.google.com/permissions.

Google API Services User Data Policy

Command Center's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
